# Asset Credits

This file records the known upstream credits for the scene assets of this
renderer. The renderer's code is MIT licensed. The assets are third-party
works, each under its own terms. They are converted, and many are
re-materialed, for this renderer. Keep the original license and readme files
in their source folders when packaging or redistributing an asset.

Five scenes are bundled in this repository (`ajax`, `ajax-other`, `ajax-glass`,
`hygieia`, `hygieia-other`). Every other scene is in the v4 asset pack.

Metal PathTracer is a non-commercial project. Some assets listed here are
licensed for non-commercial use only (CC BY-NC-SA 4.0, CC BY-NC 4.0 and
CC BY-NC-SA 3.0). They are used, and their images are shared, only for
non-commercial purposes, as those licences require. If you reuse these assets
or images, their licences apply to you.
