# Metal PathTracer v4.0.0

This release covers the work done since v3.0.0. It focuses on accuracy: many
transport and material rules were fixed, measured and checked against a CPU
reference backend. Many images change. Read the upgrade notes before you
compare renders with v3.

Development happens in a private line, and each release is imported into this
repository as a single snapshot commit.

## Source

- Repository: https://github.com/dariopagliaricci/Metal-PathTracer-arm64
- Tag: `v4.0.0`

## Build

Basic Metal build:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target PathTracer PathTracerHeadless
```

Dedicated wavefront/Metal development build:

```bash
cmake -S . -B build-metal -DCMAKE_BUILD_TYPE=Release
cmake --build build-metal --clean-first --target PathTracer PathTracerHeadless
```

Embree-enabled build:

```bash
brew install embree
cmake -S . -B build-embree -DCMAKE_BUILD_TYPE=Release -DPATH_TRACER_ENABLE_EMBREE=ON
cmake --build build-embree --clean-first --target PathTracerHeadless EmbreeSmokeTest
```

Importer build with Assimp:

```bash
brew install assimp
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target PathTracerImport PathTracerBistroAudit
```

Optional OIDN CPU denoising runtime:

```bash
OIDN_VERSION=2.4.1
curl -L \
  -o /tmp/oidn-${OIDN_VERSION}.arm64.macos.tar.gz \
  https://github.com/RenderKit/oidn/releases/download/v${OIDN_VERSION}/oidn-${OIDN_VERSION}.arm64.macos.tar.gz

tar -xzf /tmp/oidn-${OIDN_VERSION}.arm64.macos.tar.gz -C /tmp

mkdir -p external/oidn/include external/oidn/lib
cp -a /tmp/oidn-${OIDN_VERSION}.arm64.macos/include/. external/oidn/include/
cp -a /tmp/oidn-${OIDN_VERSION}.arm64.macos/lib/. external/oidn/lib/

xattr -dr com.apple.quarantine external/oidn/lib/*.dylib 2>/dev/null || true
```

Reconfigure after installing OIDN:

```bash
rm -rf build
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Main CMake options:

| Option | Default | Description |
| --- | --- | --- |
| `PATH_TRACER_ENABLE_EMBREE` | `OFF` | Build and link the Embree CPU backend. |
| `PATH_TRACER_ENABLE_ASSIMP` | `ON` | Enable the Assimp-backed importer when Assimp is found. |
| `PATH_TRACER_ENABLE_OIDN` | `ON` | Enable OIDN if vendored native libraries are present. |
| `PATH_TRACER_BUILD_EMBREE_SMOKE_ONLY` | `OFF` | Build only the Embree smoke target. |
| `PT_DEBUG_TOOLS` | `OFF` | Enable HWRT/SWRT path debug and parity tooling in the GUI target. |
| `PT_MNEE_SWRT_RAYS` | `OFF` | Force MNEE rays through SWRT for HWRT debug. |
| `PT_MNEE_OCCLUSION_PARITY` | `OFF` | Compare MNEE visibility through HWRT and SWRT. |
| `STRICT` | `OFF` | Enable strict warnings. |
| `M0_TESTS` | `OFF` | Enable optional golden-image CTest entries. |

## Highlights

- Metal camera rays now have unit length. Cutout continuations, the minimum
  distance and volume segments now read `t` as a world distance. Sponza ivy
  tile, first-hit base colour, Embree/Metal: 0.7764 to 0.9870.
- Display and LDR export use the piecewise sRGB encode by default. Shadows and
  midtones change in every LDR image. `srgbOutput=0` restores gamma 2.2.
- `ris_spatial` and `ris_world` are unbiased. On the sun-plane test they give
  2.33004 against the exact 2.33005. `ris_spatial` gave 0.822 and `ris_world`
  gave 1.92047 before.
- The RIS and ReSTIR DI modes light back-lit foliage cutouts and thin
  transmissive sheets with plain NEE's surface terms. San Miguel balcony, `ris`
  and `restir_di` against plain NEE: 0.9417 to 1.0000.
- Random-walk subsurface scattering now works on Metal. The walk matches Arnold's
  randomwalk within 0.06% (mean free path 0.1), 0.31% (0.25) and 0.08% per
  channel (marble colour) on a unit sphere under one emitter. The busts in
  `sss_marble_wax` were 2.7 to 3.2 times darker than Lambert before.
- Hero-wavelength spectral transport carries three wavelengths per path. It
  refuses unsupported combinations, including the default specular NEE, so
  spectral runs need `--enableSpecularNee=0`.
- Homogeneous volumes are more accurate. Surface NEE to positional lights is
  attenuated by the medium (quad lamp, sigma_a 0.5: 0.1947 to 0.0922, reference
  0.0921). Free flight counts the transmittance once (unscattered light through
  optical depth 1: 0.3678 to 1.0016 of exp(-1)). Meshes occlude volume NEE on
  the hardware megakernel. The Henyey-Greenstein sign follows pbrt.
- The Embree CPU backend follows Metal's rules on many more cases: alpha and
  cutout handling, sun lighting, ReSTIR DI, shadow rays, textures, subsurface and
  Tungsten source closures. It runs the shipped Bitterli presets (120/120 tiles
  pass, global Embree/Metal ratio 0.9995 to 1.0006 on the six checked). Its peak memory on big scenes is lower with
  bit-identical images (Emerald 64.0 to 20.4 GB).
- Scenes load faster with byte-identical output. Barcelona Pavilion: 92.9 s to
  23.2 s, then 23.0 s to 6.7 s in a later step. Bistro: 20.5 s to 11.9 s.
  Timings were measured on one Apple Silicon machine.
- Cold starts compile only the megakernel pipeline a run uses.
  `bitterli_veach_ajar` on the wavefront: 283 s before, 69 s now.
- The GUI renders at the drawable size times the viewport quality scale for
  every scene, and saved EXR files now open with the right colours.

## Known limits

- Explicit ReSTIR DI passes (`--restirDebug=1`) on the megakernel are refused.
  Headless runs exit with code 2 before the acceleration structures build. The
  window logs the refusal once and renders the fused `restir_di`.
- The wavefront runs `ris_spatial` as plain RIS. It logs this and sets
  `wavefront_direct_light_fallback` in the render metadata.
- Under `--volumeTransportMode=homogeneous`, Metal renders `restir_di` and the
  hybrid as `baseline_emissive`. Embree ignores volumes.
- Surface NEE through a medium attenuates positional lights only. Suns and the
  environment are not attenuated.
- Spectral mode refuses specular NEE, MNEE, volumes, RIS and ReSTIR, the
  radiance cache, SVGF, ML reconstruction, Tungsten source closures and debug
  views. The README section "Hero-Wavelength Spectral Mode" has the matrix.
- The radiance cache gives no error reduction at equal render time. Per sample,
  cache on costs 2.76 times cache off on `living_room`, 2.23 times on `sponza`
  and 1.38 times on `emerald_square_day`. It is refused with ReSTIR GI, ReSTIR
  PT path reuse and spectral mode.
- Subsurface: `method=separable` is not implemented. Normal maps are not applied
  at the exit point. The default `sssMaxSteps` is 32. Step-limit and open-mesh
  endings end the path with no light, and the log names each material that has
  them.
- Non-power-of-two mips: the environment map keeps Metal's blit chain. A
  non-power-of-two material texture in a format other than 8-bit RGBA keeps the
  blit and logs a `[MaterialTexture]` warning. Single-channel non-power-of-two
  textures have one level on Metal and a chain on Embree.
- The megakernel's fast pipeline made sponza 3.3% slower (2.54 s to 2.63 s,
  1280x720, 64 spp). Only sponza and Sun Temple were timed. The software
  wavefront's plain NEE on sponza is 6.2% slower.
- Embree refuses by name: opacity and `interfacePrecision` without source
  transport, alpha cutouts on explicit-interior materials under source
  transport, and a source texture that mixes nearest and linear filters.
  Embree takes one medium per shadow segment and does not re-select it at each
  alpha hole.
- Embree runs source features and the random walk, but ignores volumes. Its
  `restir_di` was measured against its own plain NEE on emerald_square_day
  (1.0016) and against Metal on Bistro alt (0.9961); other scenes were not
  checked.
- Homogeneous volumes: the Henyey-Greenstein glow ratio (g +0.7 over g -0.7) is
  19.6 to 25.0 against Arnold's 17.1 to 23.5. The 6-8% residual is unexplained.
- Homogeneous volume transport stays a Prototype. Only the cases quoted in the
  CHANGELOG have a measured reference.
- Software ray tracing (`--force-swrt=1`) renders `zero_day_measure_seven` at
  0.9976 of hardware ray tracing. The cause of the remaining 0.25% was not
  traced.

## Upgrade notes

Behaviour changes that a v3 user will notice:

- **Display encode.** LDR output uses the piecewise sRGB transfer function. v3
  used gamma 2.2. Set `srgbOutput=0` in the scene to get the old encode.
- **Camera rays.** Metal camera rays are unit length. Cutout continuations on
  camera rays and homogeneous-medium segments change. A camera placed within a
  few millimetres of a surface can show that surface now. A scene whose camera
  sat 2-5 mm from a door panel needed a 2 cm move.
- **Environment lighting.** HDR suns load as RGBA32F, so texels above the
  half-float range are no longer clipped. Environment sampling jitter and the
  roughness blur of the environment were fixed. Presets with HDR suns were
  recalibrated, so they look different from v3. The recalibrated presets are in
  the v4 asset pack.
- **Bundled preset recalibrations.** Presets were recalibrated, and v3 images
  are not references for v4. Bistro full sun now renders with an exposure of
  1.0 stop. A scene with `gltfEmissiveScale` set now scales Bistro's practical
  lights too: `bistro_night_openfront_restir` (scale 20) is about 15 times
  brighter, mean RGB 0.0587 / 0.0320 / 0.0167 to 0.874 / 0.453 / 0.238.
  The public tree bundles five scenes (`ajax`, `ajax-other`, `ajax-glass`,
  `hygieia`, `hygieia-other`). The Bistro presets and all other scenes are in
  the v4 asset pack.
- **Glass and plastic.** Delta specular connections, PBR delta lobes, specular
  energy compensation, thin-walled glTF transmission and the Plastic and
  CarPaint closures changed. Glass, mirrors, smooth metals and plastics look
  different.
- **Alpha.** MASK cutouts test the hit's mip-0 alpha on path rays. BLEND texels
  pass shadow rays with probability 1 - alpha. Foliage lit from behind changes.
- **Mips.** Non-power-of-two material textures get mean-preserving mip chains.
  San Miguel is 1-4% darker and barcelona_pavilion_day about 1% darker.
- **Subsurface.** `sss=randomwalk` scenes change a lot, because the walk now
  runs under the surface. `sss_marble_wax` is brighter.
- **Volumes.** The sign of `--volumeAnisotropy` is flipped to pbrt's
  convention: g greater than 0 scatters forward. No bundled or asset-pack scene
  sets `volumeAnisotropy` or `volumeTransportMode`, so none of them changes.
  Only your own scenes or command lines that set `--volumeAnisotropy` change:
  to keep the old look, use the opposite sign.
- **Direct light modes.** `ris_spatial`, `ris_world`, `ris_regir` and the hybrid
  give different values. They were biased before.
- **Wavefront.** Non-PBR base colours are read at mip 0 after the primary hit.
  The v3 wavefront rendered `bitterli_staircase` 4.7% too bright.
- **Spectral mode.** The mode was rebuilt. Runs that used it in v3 need
  `--enableSpecularNee=0` and may exit with code 2 for unsupported options.
- **Removed or inert settings.**
  - `specularTailClampBase` and `specularTailClampRoughnessScale` are removed
    from the renderer. Scene files that carry them still parse. The values are
    ignored and one note per scene load says so.
  - The `TransmissionKeepsSpecular` material flag is removed (bit 7 is unused).
  - The material flag that kept the environment at full resolution is removed,
    with the `env_lod` field of `--materialMrDebugJson`.
  - Textured-emission NEE is the per-mesh token `gltfTexturedEmissionNee=1`.
    A folder-name rule no longer applies it. Emerald Square keeps its path
    rule.
  - The GUI sliders for the two tail-clamp settings are gone.
- **Scene loads.** The GUI resets glTF load options and `directLightMode` on
  every scene load. A scene gets what its own file says, or the default.
- **GUI render size.** The render size is the drawable size times the viewport
  quality scale for every scene. A scene's `width` and `height` is its headless
  size.
- **Importer.** v3's `PathTracerImport` copied Assimp's texture coordinates
  unchanged. Assimp keeps V with a bottom-left origin for every format, glTF
  included, so every v3 import wrote V mirrored for glTF's top-left origin:
  textures were flipped vertically on the surface. v4 writes `1 - v` and
  negates `tangent.w` for every format. The import manifest records
  `"texcoord_v_origin": "top_left"`. Files that v3 wrote still load and render
  as before. Only assets imported with v3 whose V you corrected, by hand or with
  `gltfFlipTexcoordV=1`, are affected: if you re-import them with v4, remove
  that correction, or the texture flips twice.
- **Headless refusals.** Explicit ReSTIR DI passes on the megakernel and
  unsupported spectral combinations exit with code 2 before rendering.
- **Output files.** Saved GUI EXR files now carry channels in sorted order and
  alpha 1. Debug JSON writes non-finite numbers as null.

## Verification

The fixes listed in the CHANGELOG with numbers were measured on a scene or an
analytic test, against an exact value, the Embree backend or Arnold. Fixes
listed without numbers were not measured that way. This release makes no speed
claim beyond the timings listed there.
