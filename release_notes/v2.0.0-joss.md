# Metal PathTracer v2.0.0-joss - JOSS Submission Snapshot

This release is the frozen public snapshot intended for Journal of Open Source
Software submission and review of Metal PathTracer.

## Scope

- Stable v2.x renderer state prepared for JOSS review.
- JOSS paper source included under `paper/paper.md`.
- Public build and smoke-test workflow documented for reviewers.
- Active development toward `v3.0.0` continues separately after this snapshot.

## Source

- Repository: https://github.com/dariopagliaricci/Metal-PathTracer-arm64
- Tag: `v2.0.0-joss`
- Commit: the commit targeted by the `v2.0.0-joss` tag.

## Build

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

## Public Smoke Test

```bash
tests/public/headless_smoke_test.sh
```

Validation result for this snapshot: passed on Apple Silicon when run with
Metal device access enabled.

For the Embree reviewer path documented in the paper:

```bash
cmake -S . -B build-embree -DCMAKE_BUILD_TYPE=Release -DPATH_TRACER_ENABLE_EMBREE=ON
cmake --build build-embree --config Release --target PathTracerHeadless EmbreeSmokeTest
./build-embree/EmbreeSmokeTest
tests/public/headless_smoke_test.sh ./build-embree/PathTracerHeadless --backend=embree
```

Validation result for this snapshot: passed; the public Embree smoke render
produced a 66,925-byte PPM output.

## Assets

Large scene assets and HDRIs are intentionally not versioned in Git. Use the asset
pack linked from the repository README or GitHub release when reproducing
asset-dependent renderings. The public smoke test does not require external assets.

## Release Separation

This `v2.0.0-joss` release is the frozen JOSS submission snapshot. The later
`v3.0.0` public feature release is separate and should not be treated as the
frozen JOSS review version unless the JOSS submission is intentionally updated.
